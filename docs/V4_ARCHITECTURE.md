# Codex — V4 Android Architecture
App name: Codex. Package: com.raj.codex v1.0 code 1. minSdk 24, compile/target 34.
Flow: User prompt -> Manager (deterministic state machine) -> Planner -> Coder -> Tester -> Debugger (max 3 repairs) -> Reviewer -> VERIFIED/FAILED with evidence.
Modules (Kotlin): gateway (ProviderAdapter, ModelGateway, ErrorNormalizer, ModelRegistry, CircuitBreaker), providers (Gemini native; OpenAI-compatible base for OpenRouter/Groq/NVIDIA/Ollama/custom incl. ngrok tunnels — ngrok is NOT a provider), router (pure function, modes AUTO/FAST/POWERFUL/FREE_ONLY/LOCAL_ONLY/CUSTOM, fallback on 429/5xx), agents (TaskEngine, roles are specs not models), context (select relevant files only, never whole repo), tools (FileTools patch, CheckpointManager snapshot — no git CLI on Android), verification (real checks only, no fake PASS), security (keys in app-private storage only, LOW/MEDIUM/HIGH permission policy, HIGH never auto-run).
Prompt-to-app: New App flow creates Codex/<id>/index.html (web app, preview in WebView). Android App flow generates Android source; APK is NOT built on-phone — it is built by GitHub Actions (aesthetic-dhruv/codex) and downloaded, then Transfer APK shares it to a second phone (Nearby Share / Bluetooth / USB-OTG). Transfer is sending, not building.
